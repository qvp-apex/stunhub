# Key System design direction

Reading this as: a script verification gateway for users completing one group task, in a precise instrument-panel style, dial ENERGY 2 / RHYTHM 2 / MOTION 2.

- Color: deep navy grounds the verification gateway, cyan identifies the primary action, and green appears only for a real active state.
- Layout: one asymmetric task card keeps the required action as the only focal point while avoiding a generic centered template.
- Typography: Trebuchet MS gives the compact interface a slightly squared, practical voice while remaining locally available and readable.
- Spacing: generous desktop space isolates the gateway; tighter mobile spacing keeps the action visible without clipping.
- Card: the single card represents the only verification workflow instead of creating a decorative card grid.
- Shadow: only the foreground card and modal receive elevation because they sit above the page surface.
- Motion: hover lift confirms the actionable control, loading rotation communicates waiting, and the requested two-layer green pulse marks the real active status without moving surrounding content.
- Mobile: the gateway becomes a compact single-column flow, while the embed becomes a full-screen browser with safe-area spacing and persistent status controls.
- Icon: custom shield, group, and lock glyphs communicate verification, destination, and disabled access without importing a generic icon library.
- Motif: cropped corners and thin instrument lines make the interface feel like one verification system rather than a stack of decorative cards.
